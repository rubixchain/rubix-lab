Rubix Lab — quick reference for setting up a lab machine
==========================================================
Copy-paste commands only. For explanations and the full phase-by-phase
process, see SETUP-RUNBOOK.md.

1. Install Docker (Engine, not Desktop)
----------------------------------------
sudo apt update
sudo apt install -y docker.io
sudo systemctl enable --now docker     # start now AND at every boot
sudo usermod -aG docker $USER          # use docker without sudo

Log out and back in so the group change takes effect.

Check:
docker run --rm hello-world     # works without sudo
systemctl is-enabled docker     # prints: enabled

2. Get the repo and bring up the node
----------------------------------------
git clone <rubix-lab repo> ~/rubix-lab
cd ~/rubix-lab/install
LOCALNET_BOOTSTRAP_NODES='[]' ./setup.sh
# (use the real bootstrap list instead of '[]' on non-quorum machines —
# see SETUP-RUNBOOK.md Phase B)

Check:
curl -s http://localhost:20000/rubix/v1/node/ping
journalctl -u rubixgoplatform -f

3. Reference — manual Postgres container command
----------------------------------------
setup.sh normally creates the node's Postgres container for you (fixed name
rubix-node-db, port 5433). Only needed by hand if testing outside the script,
or running more than one node on the same box with a distinct name/port/volume:

docker run --name node -e POSTGRES_PASSWORD=rubixpass -e POSTGRES_USER=rubix -e POSTGRES_DB=rubix -p 5433:5432 -v pgdata_node:/var/lib/postgresql --restart always -d postgres:18

Swap "node" / "5433" / "pgdata_node" for whatever container name, host port,
and volume distinguish that node.
