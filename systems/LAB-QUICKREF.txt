Rubix Lab — quick reference: commands only, in order
=====================================================
The rebuild, top to bottom. Details/troubleshooting: SETUP-RUNBOOK.md
(the phase letters match). Everything runs on the CONTROLLER unless it says
"on the machine". Paths below are the standard ones (~/rubix-lab,
~/Desktop/rubixgoplatform); on .120 they are ~/Desktop/rubix/rubix-lab and
~/Desktop/rubix/rubixgoplatform.

A. Roles: controller/hosts.txt (fullnode .101-.104, faucet .105,
   faucet-quorum .106, controller .120, explorer .123, the rest pool)
----------------------------------------
python3 ~/rubix-lab/controller/fleet.py hosts --include-fixed

B. Controller setup (once)
----------------------------------------
sudo apt update
sudo apt install -y git python3 python3-psycopg2 python3-reportlab python3-openpyxl curl rsync build-essential
sudo snap install go --classic          # only if `go version` is older than 1.22
git clone <rubix-lab repo> ~/rubix-lab
chmod +x ~/rubix-lab/controller/*.sh ~/rubix-lab/controller/exec-update/*.sh
git clone https://github.com/rubixchain/rubixgoplatform ~/Desktop/rubixgoplatform
# copy controller/hosts.txt over (it is gitignored)
cd ~/rubix-lab/controller
./setup-ssh.sh

C. Docker Engine — on each machine that runs a node
----------------------------------------
sudo apt update
sudo apt install -y docker.io
sudo systemctl enable --now docker
sudo usermod -aG docker $USER
# log out and back in, then:  docker run --rm hello-world

D. Clear out the old installs (once)
----------------------------------------
cd ~/rubix-lab/controller
./wipe-node-db.sh --legacy --include-fixed           # dry run
./wipe-node-db.sh --legacy --include-fixed --yes     # type 'wipe'
# on .120 and .123 (no node any more), on the machine:
#   sudo systemctl disable rubixgoplatform && sudo rm /etc/systemd/system/rubixgoplatform.service
# then the two scans in SETUP-RUNBOOK D2 (old containers, old folders/keys)
# and D3 (strays on the lab key); keep .103's old reports in ~/old_reports

E. Custom build, fullnodes + bootstrap list, faucet pair
----------------------------------------
cd ~/Desktop/rubixgoplatform && git fetch origin && git checkout vaishnav/temp-custom-testnet && git pull --ff-only origin vaishnav/temp-custom-testnet && make compile-linux
cp ~/Desktop/rubixgoplatform/linux/rubixgoplatform ~/rubix-lab/systems/prerequisite/rubixgoplatform
cd ~/rubix-lab/controller
./install-nodes.sh --role fullnode
# write the 4 peer IDs into systems/bootstrap-nodes.txt (command in SETUP-RUNBOOK E1), commit, push
./install-nodes.sh --role fullnode --force
for h in 101 102 103 104; do ./restart-nodes.sh --host 192.168.1.$h --force; done
./install-nodes.sh --role faucet --role faucet-quorum

F. Faucet DIDs -> allowlist build -> mint
----------------------------------------
python3 dids-to-excel.py --host 192.168.1.105        # prints the faucet DID
python3 dids-to-excel.py --host 192.168.1.106        # prints the faucet quorum DID
# put both in CustomNetAllowedMinters (core/minterallowlist/mint_access_control.go)
# on vaishnav/temp-custom-testnet, keep Level 60001 and the ranges, commit, push
cd exec-update && ./update-exec.sh vaishnav/temp-custom-testnet 192.168.1.101 192.168.1.102 192.168.1.103 192.168.1.104 192.168.1.105 192.168.1.106
cp ~/Desktop/rubixgoplatform/linux/rubixgoplatform ~/rubix-lab/systems/prerequisite/rubixgoplatform
cd .. && python3 node-versions.py --include-fixed
# mint the faucet tokens; faucet quorum = the ONLY quorum on the faucet
# node; quorum setup on the faucet-quorum node

G. Pilot, pool, pool DIDs
----------------------------------------
./install-nodes.sh --host 192.168.1.107              # then the 3 checks in SETUP-RUNBOOK G1
./install-nodes.sh --role pool
./preflight-check.sh --include-fixed
python3 check-nodes.py --include-fixed
python3 dids-to-excel.py                             # re-run until 988 of 988

H. Smoke test
----------------------------------------
cd ~/rubix-lab/controller/test-plan/full-test
python3 smoke_test.py
for h in 101 102 103 104; do python3 -c "import psycopg2; c = psycopg2.connect(host='192.168.1.$h', port=5433, dbname='rubix', user='rubix', password='rubixpass'); cur = c.cursor(); cur.execute('SELECT count(*) FROM fullnode_transactions'); print('.$h', cur.fetchone()[0])"; done

Day to day
----------------------------------------
cd ~/rubix-lab/controller
./preflight-check.sh --include-fixed        # readiness table, one row per machine
python3 check-nodes.py                      # one row per node
./restart-nodes.sh                          # restarts only nodes that are down
./restart-nodes.sh --host <ip> --slot 3     # one node (add --force to bounce a running one)
cd exec-update && ./update-exec.sh <branch> --all --include-fixed   # deploy a build everywhere

On a machine:
journalctl -u rubixgoplatform@3 -f          # node 3's service log
tail -f ~/rubix-lab/nodes/node3/log.txt     # node 3's own log
curl -s http://localhost:20300/rubix/v1/node/ping
