Rubix Lab — quick reference: commands only, in order
=====================================================
The rebuild, top to bottom. Details/troubleshooting: SETUP-RUNBOOK.md
(the phase letters match). Everything runs on the CONTROLLER unless it says
"on the machine". Every machine keeps the lab in ~/Desktop/rubix/rubix-lab
(nodes in ~/Desktop/rubix/rubix-lab/nodes/node<slot>); the controller's product
checkout is ~/Desktop/rubix/rubixgoplatform.

A. Roles: controller/hosts.txt (fullnode .101-.104, faucet .105,
   faucet-quorum .106, controller .120, explorer .123, the rest pool)
----------------------------------------
python3 ~/Desktop/rubix/rubix-lab/controller/fleet.py hosts --include-fixed

B. Controller setup (once)
----------------------------------------
sudo apt update
sudo apt install -y git python3 python3-psycopg2 python3-reportlab python3-openpyxl curl rsync build-essential
sudo snap install go --classic          # only if `go version` is older than 1.22
git clone <rubix-lab repo> ~/Desktop/rubix/rubix-lab
chmod +x ~/Desktop/rubix/rubix-lab/controller/*.sh ~/Desktop/rubix/rubix-lab/controller/exec-update/*.sh
git clone https://github.com/rubixchain/rubixgoplatform ~/Desktop/rubix/rubixgoplatform
# copy controller/hosts.txt over (it is gitignored)
cd ~/Desktop/rubix/rubix-lab/controller
./setup-ssh.sh

C. Docker Engine — on each machine that runs a node
----------------------------------------
sudo apt update
sudo apt install -y docker.io
sudo systemctl enable --now docker
sudo usermod -aG docker $USER
# log out and back in, then:  docker run --rm hello-world

D. Clear out the old installs (once)
----------------------------------------
cd ~/Desktop/rubix/rubix-lab/controller
./wipe-node-db.sh --legacy --include-fixed           # dry run
./wipe-node-db.sh --legacy --include-fixed --yes     # type 'wipe'
# on .120 and .123 (no node any more), on the machine:
#   sudo systemctl disable rubixgoplatform && sudo rm /etc/systemd/system/rubixgoplatform.service
# then the two scans in SETUP-RUNBOOK D2 (old containers, old folders/keys)
# and D3 (strays on the lab key); keep .103's old reports in ~/old_reports

A machine back (e.g. .142) or a new one — SETUP-RUNBOOK "Bringing a machine back"
----------------------------------------
# on the machine first: Ubuntu, user rubix, its IP; after a reinstall also
# openssh-server and Docker Engine (C)
cd ~/Desktop/rubix/rubix-lab/controller
sed -i -E 's/^#[[:space:]]*(192\.168\.1\.142)([[:space:]].*)?$/\1/' hosts.txt
python3 fleet.py hosts --host 192.168.1.142
ssh-keygen -R 192.168.1.142
ssh-copy-id rubix@192.168.1.142
./wipe-node-db.sh --legacy --host 192.168.1.142               # dry run
./wipe-node-db.sh --legacy --host 192.168.1.142 --yes         # type 'wipe'
# then the old-folder scan in the runbook (must print nothing)
scp rubix@192.168.1.107:Desktop/rubix/rubix-lab/nodes/node0/rubixgoplatform ~/Desktop/rubix/rubix-lab/systems/prerequisite/rubixgoplatform
./install-nodes.sh --host 192.168.1.142
./preflight-check.sh --host 192.168.1.142
python3 node-versions.py --host 192.168.1.142 --host 192.168.1.107
python3 dids-to-excel.py --host 192.168.1.142                 # until 38 DIDs

Day to day
----------------------------------------
cd ~/Desktop/rubix/rubix-lab/controller
./preflight-check.sh --include-fixed        # readiness table, one row per machine
python3 check-nodes.py                      # one row per node
./restart-nodes.sh                          # restarts only nodes that are down
./restart-nodes.sh --host <ip> --slot 3     # one node (add --force to bounce a running one)
cd exec-update && ./update-exec.sh <branch> --all --include-fixed   # deploy a build everywhere

Node console - one machine's nodes, keys 0-8 switch live logs, s status, q back.
While a test run uses a node, the screen shows that node's log by itself (a back to that):
./fleet-console.sh                                 # pick a machine from the list
./install-console.sh --include-fixed --close-old   # put it on the machines (once, no sudo)

Live logs, from the controller (each line labelled ip:port; Ctrl+C stops):
./node-logs.sh --host 192.168.1.102                # one machine
./node-logs.sh --host 192.168.1.107 --slot 3       # one node
./node-logs.sh --role fullnode                     # the four fullnodes
./node-logs.sh --include-fixed --errors            # [ERROR]/[WARN] from every node

On a machine:
journalctl -u rubixgoplatform@3 -f          # node 3's service log
tail -f ~/Desktop/rubix/rubix-lab/nodes/node3/log.txt     # node 3's own log
curl -s http://localhost:20300/rubix/v1/node/peer_id
